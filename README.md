# Tiffin Management System

A web-based subscription and pro-rated billing system for tiffin services.

## Core Features

- Customer management
- Monthly subscriptions
- Pause/resume subscriptions
- Service-day calculation
- Pro-rated billing
- Payment tracking
- Customer search by phone
- Active/paused customer management

## Tech Stack

### Backend
- Python
- FastAPI
- SQLAlchemy
- PostgreSQL

### Frontend
- React
- Vite
- Tailwind CSS

- Git
- GitHub
